# SISTEMA DE CONSULTA DE EVENTOS METEOROLÓGICOS NO BRASIL
Este é um protótipo do site de monitoramento climático com os dados INMET. Ao decorrer do desenvolvimento, este arquivo será atualizado.

Classificação indicativa:
- Chuva horária: abaixo de 20 mm; 20–30 mm perigo potencial; acima de 30 até 60 mm perigo; acima de 60 mm grande perigo.
- Rajada: abaixo de 40 km/h; 40–60 perigo potencial; 61–99 perigo; acima de 99 km/h grande perigo.

OBS.1: Essas faixas são apresentadas como referência indicativa baseada nos valores médios das planilhas. Ela não constitui alerta oficial.
OBS.2: Horários dos arquivos CSV são UTC. Para checar em horário de Brasília, diminuir o horário UTC em 3.
